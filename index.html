This first tries Deriv’s documented public, unauthenticated market-data WebSocket. If that fails, it tries Deriv’s legacy public market-data endpoint using the published test App ID internally; you do not enter an ID. It does not log in, read balances, or place trades. If Deriv changes the public message schema or blocks the connection in your browser/network, diagnostics will show the failure.
